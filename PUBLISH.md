### 4. Создание репозитория на GitHub

1. Перейдите на https://github.com/new
2. **Repository name**: `HabitTracker`
3. **Description**: `📱 Мотивационное iOS приложение для отслеживания привычек с геймификацией, расширенной аналитикой и множеством функций. Built with SwiftUI.`
4. Выберите **Public** или **Private**
5. **НЕ добавляйте** README, .gitignore или лицензию (они уже есть в проекте)
6. Нажмите **"Create repository"**

### 5. Подключение и push

```bash
# Добавить remote (замените YOUR_USERNAME)
git remote add origin https://github.com/YOUR_USERNAME/HabitTracker.git

# Переименовать ветку (если нужно)
git branch -M main

# Отправить код
git push -u origin main
```

### 6. Добавление тега релиза

```bash
# Создать тег версии 1.0.0
git tag -a v1.0.0 -m "Release 1.0.0: Full-featured habit tracking app"

# Отправить тег
git push origin v1.0.0
```

### 7. Настройка репозитория на GitHub

После создания репозитория:

1. Перейдите в **Settings** → **General**
2. В разделе **"Topics"** добавьте все теги из списка выше
3. В разделе **"About"** добавьте:
   - Website (опционально)
   - Социальные сети (опционально)
